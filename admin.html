ALL SUITES — OVERVIEW
Run all diagnostic suites at once. Each suite validates a functional area of MixelParse by inspecting live app state via window.opener.
INVENTORY PARSER
Tests parseInventory(), extractCharName(), locationType(), getEquippedItems() with synthetic and real inventory data.
ITEM DATABASE
Validates itemDB integrity, parseItemDB() CSV parsing, classFromFilename(), raceFromFilename(), and applyDBToChar() matching logic.
WIKI STAT PARSER
Tests parseWikiStats() against known HTML snippets. Validates that stat extraction regex patterns produce correct output.
HP / MANA CALCULATIONS
Tests calcHP(), calcMana(), staRatio() across all classes and level ranges against known EQ formula outputs.
UPGRADE SCORING
Tests effectiveGain() logic, cap clamping at 255, stat delta calculation, and candidate sorting for the Upgrades tab.
GEAR STAT CHECKER
Compare two items side-by-side using the live stat weight engine. Select a character context (class, race, level) and two items from the item database to see their weighted scores and stat deltas.

PRICE BRIDGE
Live diagnostics for applyDkpToItemDB() and applyPlatToItemDB() — match counts, written values, unit conversions, and itemDB persistence. Apply bridges directly from here.
DKP PIPELINE
Tests parseDkpCsv() output structure, 60d average calculation, getDkp() lookup, dkpChip() rendering, and dkpLookup integrity.
PLAT / PIGPARSE
Validates platData shape, WTS/WTB type filtering, getPlatRows() sort/filter logic, and plat cache key invalidation.
RAID CONSUMES
Tests charHasItem(), charHasAnyOf(), getConsumeStatus(), getOverallStatus() logic against live character inventories.
FACTIONS
Validates getFaction(), setFaction(), factionColor() logic and factionData integrity for loaded characters.
SKYSHRINE TRACKER
Tests getSSDone(), tatteredName(), skyshrineData integrity, and per-class armor slot coverage.
SUPABASE / AUTH
Tests Supabase client connectivity, auth state, and confirms save/load functions exist and are wired correctly.
DROP DATA SCRAPE
One-time scrape of the P99 wiki to enrich itemDB with mob name and zone for each item. Skips items already enriched. Results are saved back to Supabase — no re-scrape needed after completion. Rate-limited to 3 items/sec to avoid wiki blocks.
